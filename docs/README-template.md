## About
Velora is a salon queue management web application. Customers join a live queue and track their token; receptionists manage walk-ins and barber assignments; barbers update service progress; a TV display shows current tokens; owners configure services and salon operations.

## Features
- Customer queue joining and private live tracking
- Reception dashboard and walk-in registration
- Barber-specific service workflow
- Waiting-area TV display
- Owner settings for services, staff and salon hours
- English/Gujarati interface
- Persistent PostgreSQL storage and real-time updates
